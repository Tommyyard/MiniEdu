# Panduan Pengguna MiniEdu

Pilih panduan sesuai peran akun Anda. Isinya mengikuti fitur yang tersedia saat ini.

- [MiniEdu Admin Guide](admin-guide.md)
- [MiniEdu Teacher Guide](teacher-guide.md)
- [MiniEdu Student Guide](student-guide.md)

Akun disiapkan pengelola; aplikasi belum menyediakan pendaftaran mandiri atau penggantian password lewat UI.

Pada form login, isi **Username / NIP / NIS** dan password: Admin memakai username, Guru memakai NIP, dan Siswa memakai NIS. Setiap orang menggunakan akun dan passwordnya sendiri.
