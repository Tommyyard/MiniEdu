# MiniEdu Student Guide

Siswa melihat nilai dan absensi miliknya sendiri serta membaca pengumuman.

## Masuk dan menu

1. Buka alamat MiniEdu yang diberikan pengelola. Pada kolom **Username / NIP / NIS**, masukkan **NIS** Anda, lalu password akun sendiri.
2. Menu Siswa: **Dashboard**, **Absensi**, **Nilai**, **Pengumuman**. Tombol **Ganti tema** mengubah tampilan terang/gelap.
3. Dashboard menampilkan ringkasan sekolah, absensi hari ini, dan pengumuman terbaru. Angkanya adalah total sekolah, bukan hanya data pribadi. Sebagian kartu menuju halaman yang tidak tersedia bagi Siswa; gunakan menu **Absensi** dan **Nilai** untuk data pribadi.

## Melihat data pribadi

- Buka **Nilai** untuk melihat nilai sendiri. Gunakan pencarian atau filter bila tersedia. Jika belum ada data, halaman menampilkan pesan kosong.
- Buka **Absensi** untuk melihat tanggal dan status kehadiran sendiri. Riwayat dibatasi hingga 100 catatan terbaru.
- Buka **Pengumuman** untuk membaca informasi sekolah.

Nilai dan absensi diambil berdasarkan akun Siswa yang sedang masuk; data siswa lain tidak tersedia.

## Keluar dan batasan

Klik **Keluar** di atas setelah selesai. Siswa tidak dapat mengubah nilai, absensi, atau pengumuman. Menu **Siswa** dan **Guru**, impor/ekspor spreadsheet, pengelolaan akun, dan penggantian password lewat UI belum tersedia untuk Siswa.
