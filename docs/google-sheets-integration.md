# Google Sheets melalui XLSX

MiniEdu mendukung workflow manual melalui export/import XLSX untuk guru dan nilai. File dapat dibuka di Google Sheets, Microsoft Excel, dan LibreOffice Calc. Gunakan template XLSX pada halaman terkait dan pertahankan NIP/NIS sebagai teks.

Google Sheets API dan sinkronisasi langsung belum diterapkan. Bila kelak diperlukan, credential API harus tetap server-side dalam environment variable; jangan memasukkannya ke repository atau Client Component. Tentukan aturan konflik data sebelum menambah sinkronisasi dua arah.
